# **App Name**: BudgetWise

## Core Features:

- Cash Expense Tracking: Record cash expenses with date and category.
- Credit Card Expense Tracking: Record credit card expenses including the total amount, number of installments, and interest rate.
- Installment Calculation: Automatically calculate and display monthly payments for each credit card expense.
- Expense Summaries and Reports: View expenses by category, payment method, or date range using filter/sort controls.
- Category Suggestion: Suggest relevant categories for each expense via a tool that identifies similar transactions.
- Import/Export Expenses: Allows the user to import and export data in standard formats like CSV.

## Style Guidelines:

- Primary color: Deep purple (#6750A4) to convey trust and sophistication in managing finances.
- Background color: Very light lavender (#F1EFF7) for a clean and calming backdrop.
- Accent color: Soft blue (#A0CAF2) used for interactive elements and important notifications.
- Body and headline font: 'Inter', a grotesque-style sans-serif with a modern look that will be easy to read.
- Use clear, minimalist icons for expense categories and credit cards.
- A clean and intuitive layout that simplifies data entry and financial overview, avoiding visual clutter.
